tracksplot#

API pages include interactive (HTML) plots that would possibly not render correctly on a mobile device.

tracksplot(data: AnnData | MuData, keys: Sequence[str] | Mapping[str, Sequence[str]] | None = None, group_by: str | None = None, *, modality: str | None = None, markers: bool | str = False, n_genes: int = 5, groups: Sequence[str] | None = None, mapping: FeatureSpec | None = None, geom: Literal['bar', 'area'] = 'bar', dendrogram: bool = False, group_bars: bool = True, group_bars_size: float = 6, group_bars_labels: bool = True, group_lines: bool = True, group_lines_color: str = '#bfbfbf', group_lines_size: float = 0.4, dendrogram_color: str = 'black', dendrogram_size: float = 0.5, dendrogram_key: str | None = None, group_lines_kwargs: dict | None = None, key_labels: bool = True, key_labels_text_size: float = 1.0, key_labels_bracket_size: float = 0.6, key_labels_text_color: str = 'black', key_labels_bracket_color: str = 'black', key_labels_width: float = 0.6, value_column: str = 'value', variable_column: str = 'variable', observation_id_column: str = 'Barcode', interactive: bool = False, max_rows: int | None = 1000, **geom_kwargs) → PlotSpec#

Tracks plot of per-cell values, one track per key, with cells ordered by group.

Parameters:

  • data (AnnData | MuData) – The single-cell data object.

  • keys (Sequence[str] | Mapping[str, Sequence[str]] | None, default None) – Variable keys to plot, one track each, top to bottom. A mapping assigns keys to group labels (no key in more than one group), drawn as brackets on the right. Must be None when markers is set.

  • group_by (str | None, default None) – The categorical key to order and group the cells by. Inferred from a precomputed ranking when markers is set.

  • modality (str | None, default None) – Which modality’s stored analysis results to use when markers or dendrogram is enabled. Required for a multimodal object holding more than one modality, and not accepted otherwise.

  • markers (bool | str, default False) – Derive keys from a precomputed ranking. Pass True to use the default ranking key, or a string to read a custom key (e.g. “rank_genes_groups_wilcoxon”).

  • n_genes (int, default 5) – Number of top genes to take per group when markers is set.

  • groups (Sequence[str] | None, default None) – Subset of groups to include when markers is set; None keeps all groups in their stored order.

  • mapping (FeatureSpec | None, default None) – Aesthetic mappings for the tracks, the result of aes(). For example, aes(fill=group_by) colors the tracks by group.

  • geom ({'bar', 'area'}, default 'bar') – Draw each cell as a bar, or each track as a filled area.

  • dendrogram (bool, default False) – Whether to order the groups by a dendrogram and draw it above the tracks. Computed from the data if not already stored.

  • group_bars (bool, default True) – Whether to draw a colored bar below the tracks marking group spans.

  • group_bars_size (float, default 6) – Size (thickness) of the group bar.

  • group_bars_labels (bool, default True) – Whether to label the group spans along the x-axis. Removes the related legend.

  • group_lines (bool, default True) – Whether to draw vertical lines separating the groups.

  • group_lines_color (str, default '#bfbfbf') – Color of the group separator lines.

  • group_lines_size (float, default 0.4) – Size (thickness) of the group separator lines.

  • dendrogram_color (str, default 'black') – Color of the dendrogram segments.

  • dendrogram_size (float, default 0.5) – Size (thickness) of the dendrogram segments.

  • dendrogram_key (str | None, default None) – Specific key holding the precomputed dendrogram. By default, dendrogram_{group_by} is used.

  • group_lines_kwargs (dict | None, default None) – Additional parameters to pass to the group separator lines geom_segment.

  • key_labels (bool, default True) – Whether to draw bracket labels on the right when keys is a mapping.

  • key_labels_text_size (float, default 1.0) – Scale multiplier on the auto-computed bracket label text size.

  • key_labels_bracket_size (float, default 0.6) – Size (thickness) of the bracket lines.

  • key_labels_text_color (str, default 'black') – Color of the bracket label text.

  • key_labels_bracket_color (str, default 'black') – Color of the bracket lines.

  • key_labels_width (float, default 0.6) – Bracket extent (in track units) for a singleton group. Multi-key groups extend key_labels_width / 2 past the first and last track center.

  • value_column (str, default 'value') – Name for the value column after unpivoting.

  • variable_column (str, default 'variable') – Name for the variable column after unpivoting.

  • observation_id_column (str, default 'Barcode') – Name for the cell identifier column.

  • interactive (bool, default False) – Whether to add the interactive toolbar.

  • max_rows (int | None, default 1000) – Maximum number of cell columns. Cells within a group are binned into about this many columns in total (at least one per group), each showing the mean of its cells. None draws every cell.

  • **geom_kwargs – Additional parameters passed to the track geom (geom_rect for bars, geom_ribbon for areas).

Returns:

PlotSpec – The tracks plot.

Raises:

  • UnsupportedDataTypeError – If data is not an AnnData or MuData object.

  • InvalidArgumentError – If keys or group_by is missing without markers, or geom is not one of the accepted values.

  • KeyError – If group_by is not found.

  • VariableNotFoundError – If a key is not found.

Notes

Every track has its own scale: values are divided by the largest absolute value of that key, so the tallest cell of each track reaches the full track height. The unscaled values stay in value_column for tooltips.

Examples

import cellestial as cl

data = cl.datasets.pbmc3k()
cl.tracksplot(data, keys=["CD3D", "MS4A1", "LYZ", "NKG7"], group_by="leiden")

Color the tracks by group and draw them as areas.

from ggrust import aes

cl.tracksplot(
    data,
    keys=["CD3D", "MS4A1", "LYZ", "NKG7"],
    group_by="leiden",
    mapping=aes(fill="leiden"),
    geom="area",
)
