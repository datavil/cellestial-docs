versions#

API pages include interactive (HTML) plots that would possibly not render correctly on a mobile device.

versions()#

Print the in-use versions of the packages and python.

Examples

import cellestial as cl

cl.versions()

cellestial  : 0.58.2
lets-plot   : 4.11.0
scanpy      : 1.12
anndata     : 0.12.14
polars      : 1.40.1
Python      : 3.14.6
