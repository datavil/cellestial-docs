Migrating to the v1 API#

The v1 API review renamed several parameters so that each name means one thing across the library. Old names no longer pass through silently: a renamed or removed keyword raises UnknownParameterError (a TypeError) that names the replacement.

Private Helpers#

  • anndata_observations_frame, anndata_variables_frame and anndata_variable_columns are private. Build frames with build_frame().

  • DeferredLayer is private. Add the layer returned by a layer function (cl.bracket, cl.stream, …) to the plot instead of constructing it.

  • SpatialLibraryError is removed; it was never raised. Drop it from imports and except clauses.

Errors#

Every cellestial error lives in cellestial.errors (also cl.errors) and subclasses both CellestialError and the builtin it replaces, so existing except KeyError or except ValueError clauses keep working.

try:
    cl.umap(data, "leiden", use_key="X_umap")
except cl.errors.UnknownParameterError as error:
    print(error)  # names embedding_key as the replacement

try:
    cl.umap(data, "leidn")
except cl.errors.CellestialError as error:
    print(error)  # suggests 'leiden'

Some failures changed class: unknown keys now raise KeyNotFoundError (a KeyError) instead of ValueError. Catch KeyError or KeyNotFoundError for those cases.

Dataset Changes#

The dataset that cl.datasets.pbmc3k() used to load is renamed to bone_marrow(). It was never the 10x PBMC 3k: it holds about 17,000 bone marrow mononuclear cells (samples s1d1 and s1d3) from the scanpy “Preprocessing and clustering” tutorial, with the same cell_type_lvl1 and leiden_res_* columns. Replace cl.datasets.pbmc3k() with cl.datasets.bone_marrow() to keep the old data. Its cell_type_lvl1 column had “B Cells” and “Erythroid” swapped and left the erythroblast cluster null; the labels are corrected and the column has no nulls.

pbmc3k() now loads the real 10x Genomics PBMC 3k: 2,638 cells processed as in the scanpy PBMC 3k tutorial, annotated in cell_type. Code written for the old pbmc3k raises KeyNotFoundError on cell_type_lvl1 or leiden_res_0.02.

New in v1#

  • outline=True on the dimensional plots draws a scanpy-style border around the point cloud. outline_width and outline_color set the border and gap.

  • volcano and volcanos take min_fraction_expressed (e.g. 0.1) to drop features detected in too few cells of the group.

  • build_frame returns categorical metadata as pl.Enum in the source category order, so legends list categories as the data defines them.

The full list of changes is in the changelog.
